# 优化行业成分数据与 dashboard 行业口径

## 摘要

补齐行业主线模块背后的行业成分股数据链路，让 dashboard 能优先使用完整行业成分股，而不是只用沪深 300 或本地缓存样本代理。同时增强页面的数据口径提示，让用户能一眼判断当前行业榜和下游股票池是“全行业成分股”还是“样本代理”。

## 背景与动机

当前 dashboard v1 已经把行业主线证据板放在数据健康条下方，并支持点击行业后服务端重算下游流程。但实际排查发现：

- `industry_members` 规范化表为空，无法提供完整行业成分股。
- `sync --dataset industry_boards` 只同步行业板块列表，不同步每个行业的成分股。
- 页面只能退化为 `指数样本代理` 或 `缓存样本代理`，导致光学光电子 2 只、半导体 20 只、元件 8 只这类明显偏少的行业数量。
- 样本过小时，涨幅、上涨家数占比、成交额和回撤指标容易失真。

因此需要把行业数据链路从“展示层有降级提示”推进到“数据层能稳定提供完整行业成分，并在不可用时透明降级”。

## 范围

本次包含：

- 新增或扩展行业成分股同步能力，把每个行业板块的成分股写入 `industry_members`。
- 让 dashboard 在选中行业时优先读取 `industry_members` 中的行业全成分股。
- 当完整行业成分不可用时，继续允许降级为当前基础池样本，但必须明确标注样本来源、样本数量和降级原因。
- 调整行业主线证据板和数据健康/summary 字段，区分全成分股、指数样本代理、缓存样本代理。
- 让 dashboard 快照和数据指纹能感知行业成分数据变化，避免复用旧的样本代理结果。
- 增加测试覆盖行业成分同步、全成分优先、样本降级和页面口径展示。
- 更新文档，记录行业数据同步命令、数据表契约、降级规则和使用限制。

本次不包含：

- 修改行业主线排序公式、宏观粗筛公式、技术分析公式或操作建议规则。
- 引入自动交易、收益承诺、个人预算或仓位配置。
- 把样本代理结果包装成完整行业强弱榜。
- 要求每次 dashboard 打开都远程刷新全市场行业成分；本地 cache/offline 行为仍需保留。

## 成功标准

- 执行行业数据同步后，`industry_members` 不再为空，并能按行业名查询成分股。
- dashboard 选中某个行业时，若该行业在 `industry_members` 中有可用成分，`股票池` 阶段使用完整行业成分股。
- 行业全成分股可用时，页面显示 `行业全成分股` 和真实成分数量。
- 行业成分缺失时，页面明确显示 `指数样本代理` 或 `缓存样本代理`，并展示降级原因。
- 行业成分数据变化后，dashboard-server 不继续复用旧快照或旧响应缓存。
- 所有下游阶段仍保持串行：`股票池 -> 宏观粗筛 -> 技术分析 -> 操作建议`。
- 本项目仍定位为研究和辅助决策工具，不构成投资建议。
