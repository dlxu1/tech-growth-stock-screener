# 将行业主线证据板合并进 dashboard v1

## 摘要

将已经验证过的行业主线交互方向合并进现有 `dashboard` v1，而不是继续演进独立 `dashboardv2` 页面。新的 v1 页面应在 `数据健康` 模块下方、`宏观潜力 × 技术时机`/`高潜力+好时机` 决策区上方插入“行业主线证据板”。页面默认选中行业主线排名第一的行业，并让下方高潜力与好时机分析基于该行业的股票池继续运行。

## 背景与动机

当前项目原先以沪深 300 作为 dashboard 默认股票池，再通过宏观粗筛和技术分析找出候选。这能覆盖足够多的股票，但用户仍会遇到两个核心问题：

- 结果黑盒感较强，技术面信息占主导，不容易建立买入信心。
- 候选股过多且偏短线，需要频繁盯盘。

前一版 `dashboardv2` 已经证明“行业主线 -> 主线股票池 -> 龙头收敛 -> 技术确认 -> 每日复盘”的交互方向更符合用户心智。但用户希望保留当前 v1 的成熟交互，不再维护一套独立 v2。因此本次变更的重点是把行业证据层作为 v1 的上游决策模块，而不是继续扩展 `dashboardv2`。

## 范围

本次包含：

- 在现有 `dashboard` v1 中插入行业主线证据板。
- 行业证据板位于数据健康模块下方、高潜力与好时机模块上方。
- 默认选中行业主线排名第一的行业。
- 下方宏观潜力、技术时机、操作建议和每日复盘基于选中行业的股票池继续运行。
- 复用现有数据缓存、行业主线证据排序骨架、宏观粗筛、技术分析和操作建议能力。
- 暂停 `dashboardv2` 独立页面的后续功能更新，仅保留兼容入口或降级说明。
- 明确“选中行业股票池”的数据来源、完整性提示和降级规则。

本次不包含：

- 继续美化或扩展独立 `dashboardv2` 页面。
- 引入自动交易、仓位预算或收益保证。
- 静默修改宏观粗筛、技术分析、操作建议的评分公式。
- 在行业数据不足时编造行业上涨原因或把结果包装成完整行业指数结论。

## 成功标准

- 用户打开 `dashboard` v1 时，先看到数据健康，再看到行业主线证据，再进入现有高潜力与好时机决策区。
- 默认行业是行业主线榜排名第一的行业。
- 高潜力与好时机模块的候选范围明确来自当前选中行业，而不是默认沪深 300 全池。
- 如果行业全成分股数据不可用，页面必须明确提示当前使用的是缓存样本或指数内行业样本，不得让用户误以为已覆盖行业所有股票。
- `dashboardv2` 不再作为新交互的主入口继续更新，后续改动集中到 v1。
