# 为高潜力好时机股票添加投资周期标记

## 摘要

为 dashboard 中落入 `高潜力 + 好时机` 象限的股票增加投资周期标记，让交互视图能区分每个候选股更适合长线跟踪、中线波段观察、短线执行，或多种周期同时适用。

## 背景与动机

当前 dashboard 已经把宏观潜力和技术时机分开展示，但用户仍需要从分项得分和策略命中里自行推断适合的决策周期。一个“高 ROE + 合理估值”的股票，不应该和一个主要靠突破或放量确认触发操作计划的股票被同样解读。

本变更把已经实现的策略意图显性化到交互层：

- 长线标记强调质量、估值、持续增长和回撤控制。
- 中线标记强调宏观潜力与技术趋势/时机确认。
- 短线标记强调可执行操作计划，包括入场、止损和风险字段。

这些标记只作为研究注释，不得变成投资建议、仓位建议或自动交易指令。

## 范围

本次包含：

- 基于现有 dashboard 行和已经实现的策略输出计算投资周期注释。
- 在潜力-时机矩阵详情面板中，为 `高潜力 + 好时机` 股票展示周期标记。
- 将 `策略口径` 和 `权重版本` 作为全局信息放入现有数据健康栏。
- 在操作建议/dashboard 模型中增加周期字段，供表格、搜索和后续回测使用。
- 在每日邮件摘要中展示新增的个股周期信息，确保邮件与 dashboard 使用同一套标记口径。
- 记录计算和展示契约。
- 增加针对分类、阶段完整性、dashboard 渲染和邮件摘要的聚焦测试。

本次不包含：

- 新增股息率、支付率、现金流覆盖、波动率或 beta 数据源。
- 修改宏观、技术、操作建议或矩阵阈值。
- 修改 `combo_score`、`technical_score`、`attention_score` 或操作建议执行规则。
- 增加个人配置、预算或账户相关建议。

## 成功标准

- 当现有证据足够时，`高潜力 + 好时机` 股票至少展示一个投资周期标记。
- 当多组证据同时满足时，同一股票可以拥有多个标记，例如 `长线` 和 `中线`。
- 只有在操作计划可执行且风险字段完整时，才展示短线标记。
- 长线标记必须基于基本面、质量和估值证据，不能只因为短期价格强势而触发。
- 数据缺失时给出保守说明，不强行打标。
- 每日邮件中每只 `好时机 + 高潜力` 股票展示 `适合周期`、`优先关注` 和简短原因；JSON payload 同步包含对应字段。
- Dashboard 输出仍保持串行研究流程：`股票池 -> 宏观粗筛 -> 技术分析 -> 操作建议`。
