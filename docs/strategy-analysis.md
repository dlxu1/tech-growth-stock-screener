# 选股策略分析文档

> 生成日期：2026-07-13 | 数据截至：2026-06-30 | 股票池：CSI 300

## 一、整体流程

选股流程是一条严格的串行管线，下游阶段只消费上游的结果：

```
股票池 (CSI 300) → 宏观粗筛 (≤100只) → 技术分析 (全量) → 操作建议
```

最终输出一个 **宏观潜力 × 技术时机** 矩阵，将股票分为四个象限：

| | 技术分 < 75 | 技术分 ≥ 75 |
|---|---|---|
| **宏观分 ≥ 80** | 高潜力·时机未到 | **好时机+高潜力** |
| **宏观分 < 80** | 低关注区 | 时好·潜力不足 |

## 二、宏观粗筛分 (combo_score)：回答"值不值得跟踪"

### 2.1 核心公式

```
combo_score = 
    overlap_score      × 0.35   ← 多策略共振分
  + growth_score       × 0.20   ← 成长分
  + quality_score      × 0.18   ← 质量分
  + risk_control_score × 0.15   ← 风控分
  + liquidity_score    × 0.07   ← 流动性分
  + momentum_score     × 0.05   ← 动量分
```

### 2.2 各子分计算

**overlap_score（多策略共振分，权重 35%）**

从 6 个精选策略中跑，每个策略在 CSI 300 内独立排名取 Top N，再统计每只股票被多少个策略同时命中：

| 策略 | 含义 | 权重 |
|---|---|---|
| `market_cap_revenue_profit_growth` | 市值前排 + 营收净利双增长 | 1.25 |
| `high_roe_reasonable_pe` | 高 ROE + PE 接近行业中枢 | 1.15 |
| `low_drawdown_positive_growth` | 回撤较小 + 正增长 | 1.15 |
| `high_gross_margin_revenue_growth` | 高毛利率 + 营收增长 | 1.00 |
| `active_amount_solid_fundamentals` | 成交额活跃 + 基本面不差 | 1.00 |
| `price_strength_market_cap` | 价格强势 + 市值前排 | 0.75 |

总权重 = 6.30。overlap_score = 命中的策略权重之和 / 6.30 × 100。

设计意图：单策略容易误杀或过度集中，多策略共振意味着股票在好几种可靠维度上同时排进前列。

**growth_score（成长分，权重 20%）**

对 revenue_yoy（营收同比）和 profit_yoy（净利润同比）分别取非负裁剪后的 cross-sectional percentile rank，二者加总再 rank → 0-100 分。只有双增才得高分。

**quality_score（质量分，权重 18%）**

```
quality = rank_high(ROE) × 0.45 + rank_high(毛利率) × 0.30 + PE_合理度 × 0.25
```

PE 合理度：PE 离行业 PE 中位数越近分越高，偏离超过 2 倍中位数则归零。这避免了单纯低 PE 偏好——一个行业中 PE 适中且 ROE 高的公司才得分。

**risk_control_score（风控分，权重 15%）**

```
risk_control = rank_low(|max_drawdown_252d|) × 0.70 + rank_high(amount_20d) × 0.30
```

70% 看年内最大回撤越小越好，30% 奖励成交额大（流动性本身也是一种风险缓冲）。

**liquidity_score（流动性分，权重 7%）**

纯 percentile rank of 20 日均成交额 → 0-100。成交额过低会导致买卖滑点大、止损难以执行。

**momentum_score（动量分，权重 5%）**

纯 percentile rank of 60 日收益率 → 0-100。权重最小，只做辅助参考。

### 2.3 公式设计逻辑

权重的设计逻辑很清晰：

- **overlap_score（35%）是绝对核心**——多策略同时认可意味着多个维度交叉验证，比任何单一指标都可靠
- **growth（20%）+ quality（18%）= 38%** 是基本面中军——回答"公司是否在变好且质地不错"
- **risk_control（15%）+ liquidity（7%）= 22%** 是安全垫——回撤可控、流动性充足才能在不利行情中从容退出
- **momentum（5%）最小**——短期涨跌容易反转，过度依赖动量会导致在高位接盘

## 三、技术分 (technical_score)：回答"现在是不是好时机"

### 3.1 核心公式

```
technical_score = 
    trend_score      × 30  ← 趋势分
  + momentum_score   × 20  ← 动量分（技术面）
  + volume_score     × 20  ← 量能分
  + breakout_score   × 15  ← 突破分
  + risk_score       × 10  ← 风险分（技术面）
  + liquidity_score  ×  5  ← 流动性分
```

理论满分 100，各子分内部有 cap（min(子分, 1.0)），防止某一项过度拉高总分。

### 3.2 子分判定规则

**趋势分（权重 30）**

| 条件 | 得分 |
|---|---|
| 收盘价 > MA20 | +0.35 |
| MA5 ≥ MA10 ≥ MA20（多头排列） | +0.35 |
| MA20 近 6 日斜率向上 | +0.30 |

满分 1.0，意味着价格站在均线上方、均线多头排列且趋势向上。缺一则相应扣分。

**动量分（技术面，权重 20）**

| 条件 | 得分 |
|---|---|
| 20 日收益 > 0 | +0.40 |
| MACD 柱 > 0 | +0.35 |
| RSI 在 50-75 区间（温和偏强） | +0.25 |
| RSI 在 45-50 区间（接近中性偏多） | +0.12 |

关键设计：RSI 过高（>75）不额外加分——避免追高。RSI 在 50-75 的温和偏强区间才是理想买点。

**量能分（权重 20）**

| 条件 | 得分 |
|---|---|
| 当日成交额 / 20日均成交额 ≥ 1.2 | +0.55 |
| 当日涨跌幅 > 0（价涨量增） | +0.35 |
| 20 日均成交额 ≥ 最低门槛 | +0.10 |

**突破分（权重 15）**

| 条件 | 得分 |
|---|---|
| 收盘价 ≥ 前 20 日最高价（突破新高） | +0.55 |
| 收盘价 / 20 日最高价 ≥ 0.98（逼近新高） | +0.25 |
| 收盘价在当日高低区间 65% 以上（强势收盘） | +0.20 |

**风险分（技术面，权重 10）**

| 条件 | 得分 |
|---|---|
| 20 日内最大回撤 ≥ -8%（轻微回撤） | +0.60 |
| 20 日内最大回撤在 -15% 到 -8%（中等回撤） | +0.35 |
| ATR% ≤ 6%（低波动） | +0.40 |
| ATR% 在 6%-10%（中等波动） | +0.20 |

两个维度独立得分可叠加——既回撤小又波动低的股票可得满分。

**流动性分（权重 5）**：20 日均成交额 ≥ 门槛则 +1.0，否则 0。

### 3.3 技术分设计逻辑

权重分配反映了「顺势但不追高」的核心理念：

- **趋势分（30%）最重**——趋势是你的朋友，价格在均线上方且多头排列意味着短期方向明确
- **量能分（20%）+ 突破分（15%）= 35%**——放量突破才是有效突破，缩量新高往往是假突破
- **动量分（20%）**——RSI 50-75 的温和区间设计避免了极端超买区追入
- **风险分（10%）**——低位回撤小+波动低的股票更容易设止损
- 总分用 min() 做 cap，防止某一只单项（如趋势极强但无量、无突破）虚高

## 四、综合关注分 (attention_score)：融合宏观与技术

```
attention_score = combo_score × 0.65 + technical_score × 0.35
```

宏观潜力占 65%、技术时机占 35%。这个权重体现了选股理念：**基本面决定值不值得跟踪（65%），技术面决定现在是否是好时机（35%）**。即使技术面一般，只要基本面扎实，仍然值得放入关注列表等待时机。

## 五、操作建议生成规则

### 5.1 策略分派

根据技术分和技术理由自动匹配策略：

| 技术分 | 技术理由包含 | 策略 | 含义 |
|---|---|---|---|
| ≥ 80 | 放量突破 | `breakout_buy` | 允许条件买入 |
| ≥ 70 | 趋势强 | `pullback_ma_buy` | 等待回踩买入 |
| ≥ 60 | 量能改善/动量较好 | `volume_confirm_buy` | 等待放量确认 |
| < 60 | - | `no_trade` / `watch` | 暂不交易/观察 |

### 5.2 关键价位计算

- **planned_entry**：
  - breakout_buy：前 20 日高点 × (1 + breakout_buffer)，默认 buffer 约 0.5%
  - pullback_ma_buy：MA20 ~ MA20 × 1.02 区间
  - volume_confirm_buy：取突破触发价，同时记录量能确认门槛

- **initial_stop**：entry × (1 - stop_pct)，或 ATR 1.5 倍止损，取更紧者

- **take_profit_1r / take_profit_2r**：1 倍和 2 倍风险距离的止盈位

- **position_cap**：技术分 ≥ 85 给满仓位，≥ 75 给 ≤ 20%，≥ 60 给 ≤ 12%

### 5.3 A 股 T+1 约束

操作回测严格遵循 A 股 T+1：买入当天不可卖出，即使当天触及止盈/止损也视为无效，卖出从次日开始。

## 六、"好时机+高潜力"是否是最安全的选择？

### 6.1 信号有效性验证机制

系统通过 `signal-validate` 命令对历史信号日进行回测验证：

- 以历史某日为信号日，用当时可见的全部数据重新跑完整流程
- 将所有候选股按 macro_potential ≥ 80 和 technical_timing ≥ 75 分入四个象限
- 按 attention_score 排名分桶（Top 1-10, Top 11-20...）
- 计算每个象限/桶在 7/14/21 个交易日后的持有收益

看板上的 `信号验证与预警` 模块展示：
- 象限热力图（各象限样本数、平均收益、中位收益、胜率）
- attention_score 桶的收益柱状图
- `象限失效预警`：好时机+高潜力 vs 其他象限的对比

### 6.2 预警规则

- 好时机+高潜力完整样本 < 5：显示「样本不足」
- 好时机+高潜力平均收益低于其他象限：触发黄色「单日观察」（< 3 个信号日）或红色「触发」（≥ 3 个信号日）
- 排序有效性：Top 1-10 vs Top 11-20，同样需要 ≥ 5 样本和 ≥ 3 个信号日才触发红色警告

### 6.3 核心判断

**好时机+高潜力不是绝对安全的选择，而是当前评分体系下"最有可能"跑赢的选择**。原因：

1. **宏观潜力来自多策略交叉验证**。不是单一指标选出来的，而是 6 个不同维度的策略同时给出高分，意味着基本面在多个角度都有支撑。这种共振本身就过滤了大量噪声和偶然性。

2. **技术时机过滤了追高风险**。RSI 在 50-75（而非 > 75）加分、突破需要放量配合、回撤小加分——这些规则刻意避开了「高位接盘」的陷阱。

3. **信号验证是独立于评分的**。即使评分逻辑完美，市场也可能在某个阶段不按这个逻辑走。信号验证模块的存在就是为了持续监控：「好时机+高潜力」是否真的在跑赢其他象限。一旦失效警告触发，说明评分信号可能需要重新校准，而不是盲目坚持。

4. **操作回测进一步模拟执行层面**。它不光看持有收益，还模拟了买入触发、止损、止盈的完整路径——这和纯粹的信号分组回测（固定持有 N 天）是互补的：信号验证回答"评分对不对"，操作回测回答"执行赚不赚"。

### 6.4 局限与风险

1. **财务数据滞后**。当前使用 2026Q1 财报数据，已滞后近 4 个月。Q2 季报发布后（8 月底前），评分可能大幅变化。

2. **CSI 300 本身就是大盘蓝筹池**。这个池子里的股票天然质地优于全市场，但成长性偏弱。如果市场风格切换为中小盘成长，CSI 300 池可能整体跑输。

3. **momentum 权重最小是双刃剑**。避免追高的同时也可能错过趋势延续的利润。在单边牛市中，高动量股票往往继续跑赢。

4. **阈值 80/75 是经验性的**。macro_potential ≥ 80 和 technical_timing ≥ 75 的象限线是预设的，不同市场环境下最优阈值可能不同。信号验证模块就是用来检测这个的。

5. **没有行业轮动和宏观择时**。当前策略是纯选股策略，不判断整体市场方向。在系统性下跌中，即使"好时机+高潜力"股票也大概率下跌，只是跌得少一些。

## 七、迭代建议

1. **定期跑 signal-validate 多日批量验证**（如 `--validation-start` + `--validation-end`），收集足够样本后判断阈值是否需要调整。

2. **关注 Q2 季报窗口**（8 月）。季报集中发布期间评分会有剧烈变化，适合做一次事件驱动回测。

3. **考虑引入行业 beta 中性化**。CSI 300 中金融和消费权重高，如果 combo_score 纯粹按 cross-sectional rank，可能系统性偏好某些行业。行业中性化可以让选股更分散。

4. **操作建议中的止损策略可以参数化回测**。当前默认 stop_pct + ATR 双保险，但最优止损幅度在不同波动率环境下不同，可以跑参数扫描。

5. **阈值自适应**。将 macro_potential 和 technical_timing 的象限分割线从固定值改为基于 rolling 历史分位数（如过去 60 个交易日的 70 分位），让象限定义随市场波动率自适应。

## 九、基于历史回测数据的优化建议（2026-07-13）

以下分析基于 4 个信号日的实际回测数据（2025-12-31、2026-01-30、2026-03-31、2026-04-30、2026-05-29、2026-06-30），涵盖了完整的市场周期。

### 9.1 核心发现：评分信号的单调性在 7 日窗口失效，在 14-21 日窗口复活

这是最关键的发现。以 2026-05-29 为例：

| attention_score 桶 | 7日平均收益 | 14日平均收益 | 21日平均收益 |
|---|---|---|---|
| Top 1-10 | +2.70% | +13.47% | +16.10% |
| Top 11-20 | -0.27% | +17.05% | +26.48% |
| Top 81-90 | -1.13% | -4.72% | -8.17% |
| Top 91-100 | -2.91% | -6.93% | -8.58% |

**7 日窗口**：Top 1-10 确实好于末尾桶（+2.70% vs -2.91%），但中段桶（Top 51-80）的表现经常好于 Top 10。单调性很差。

**14 日窗口**：Top 1-10 13.47%，Top 91-100 -6.93%。头部和尾部的差距拉大到 20 个百分点。但 Top 11-20 的 17.05% 甚至超过了 Top 10。

**21 日窗口**：Top 1-20 合计远超其他桶，单调性在头部 vs 尾部之间非常显著。

结论：**当前 attention_score 在区分「极好」和「极差」上有效，但在相邻桶之间的区分度不足。** 这是 percentile rank 方法的固有缺陷——CSI 300 池中段股票的分数差异本身就是噪声。

### 9.2 核心发现：「好时机」比「高潜力」更值钱——但这个关系在逆转

对比四个信号日：

| 信号日 | 好时机+高潜力 7日 | 高潜力+等时机 7日 | 好时机+高潜力 14日 | 高潜力+等时机 14日 |
|---|---|---|---|---|
| 2026-03-31 | N/A | +9.41% | N/A | +19.34% |
| 2026-04-30 | +14.36% | +8.43% | +39.74% | +12.75% |
| 2026-05-29 | +1.11% | -1.07% | +9.08% | +14.16% |
| 2026-06-30 | N/A | N/A | N/A | N/A |

**2026-03-31**：高潜力+等时机在 7/14/21 日完胜其他所有象限（14日 +19.34%，21日 +21.05%，胜率 83%）。这个信号日没有出现「好时机+高潜力」——说明当时技术面普遍偏弱，但宏观基本面好的股票在后续获得了巨大回报。**这是「在悲观时买基本面」的完美案例。**

**2026-04-30**：「好时机+高潜力」炸裂——4 只股票 7 日平均 +14.36%、14 日 +39.74%、21 日 +29.94%，全部盈利。**这是「宏观与技术共振」的理想状态。**

**2026-05-29**：「好时机+高潜力」只有 4 只，7 日勉强正收益，但 14 日 +9.08% 被「高潜力+等时机」的 +14.16% 反超。市场轮动开始——高潜力但技术面尚未启动的股票后续补涨。

**2026-06-30**：所有象限 7 日全绿。Top 1-10 平均 -2.09%（胜率 20%），Top 81-90 反而 +5.63%（胜率 90%）。**评分完全反向——高分股票跌得最狠。** 这正好是 6 月底到 7 月初科技股剧烈回调的时期。

### 9.3 优化建议（按优先级排序）

**建议 1（高优先级·立即可做）：加入市场状态过滤器**

当前策略在任何市场环境下都输出同样的评分逻辑。但回测数据清楚地显示：在市场整体下跌期（如 2026-06-30），高分股票因为前期涨幅大，反而回调更猛。而在震荡或上行期（2026-03-31 到 2026-05-29），评分信号的区分度显著更好。

具体方案：
- 加一个市场状态判定：CSI 300 指数 20 日均线方向 + 指数收盘在 MA20 之上/之下
- 指数在 MA20 之下且 MA20 向下 → 市场状态 = `防御`，此时降低操作建议中 `breakout_buy` 和 `pullback_ma_buy` 的仓位上限（如 max_position 打六折），同时将 combo_score 中 momentum_score 权重临时降为 0
- 指数在 MA20 之上且 MA20 向上 → 市场状态 = `正常`，维持当前逻辑

这个改动的代码量很小——在 `pipeline.py` 的 `_attention_ranked_candidates` 前加一层判断即可，不需要动评分公式本身。

**建议 2（高优先级·需要数据积累）：引入行业中性化**

当前 combo_score 是 pure cross-sectional rank，而 CSI 300 中金融和消费天然市值大、ROE 稳定、回撤小，容易系统性霸占高分段。从 2026-06-30 的 Top 10 明细可见，科技股（东山精密、中际旭创、新易盛、沪电股份、胜宏科技、兆易创新）在 7 日内全线暴跌——这些股票前期涨幅大、波动率高，宏观分高是因为增长指标好，但风控分（max_drawdown）会在牛市中虚假偏高。

具体方案：
- 在 combo_score 计算中，对 quality_score 和 risk_control_score 做行业中性化：每个行业内排名后再映射到 0-100，而非跨行业统一排名
- 这样可以避免「稳健行业天然高分」和「高波动行业天然低分」的系统性偏差

**建议 3（中优先级·需验证）：矩阵阈值从绝对值改为滚动分位数**

当前 macro_potential ≥ 80 和 technical_timing ≥ 75 是固定值。但不同市场状态下分数分布差异很大：

- 2026-04-30（牛市环境）：「好时机+高潜力」只有 4 只（因为大家都高，阈值就显得太松了）
- 2026-03-31（震荡环境）：「好时机+待复核」12 只，「高潜力+等时机」12 只

固定阈值的问题在于：牛市中几乎所有股票技术分都偏高，导致「好时机」象限膨胀，失去了筛选意义。熊市中又可能几乎没有股票进「好时机」象限，导致无股可买。

具体方案：
- 将阈值改为滚动分位数，如 combo_score 的 70 分位作为 macro_potential 线，technical_score 的 65 分位作为 technical_timing 线
- 这样「好时机+高潜力」始终是当前市场中最优秀的约 10-15% 的股票，不会因为市场整体水位涨落而失焦

**建议 4（中优先级·需要更多信号日数据）：分市场状态分别校准因子权重**

回测数据暗示：在不同市场阶段，应该侧重不同的因子。

- 下跌末期/震荡期（如 2026-03-31）：基本面因子（growth_score + quality_score）的预测力最强。此时「高潜力+等时机」的 14 日收益 +19.34% 远超其他组合。
- 上涨中期（如 2026-04-30）：动量因子和趋势因子的预测力最强。「好时机+高潜力」14 日 +39.74%。
- 上涨末期/过热期（如 2026-06-30）：所有多头因子失效，此时应该降仓位而非调因子。

建议积累至少 12 个信号日数据后，分市场状态回归因子权重。在此之前，不要手动调整公式——容易过拟合单日数据。

**建议 5（低优先级·探索性）：attention_score 中 macro 和 technical 的 65/35 权重可能需要动态化**

当前 attention_score = combo × 0.65 + technical × 0.35。但从 2026-03-31 的数据看，纯宏观驱动的「高潜力+等时机」在 14/21 日持有期上大幅跑赢了「好时机+高潜力」。这意味着在某些市场阶段，**等待时机的耐心比追逐时机更重要**，宏观潜力应该获得更高的权重。

可以设计一个基于市场波动率的动态权重：当 VIX 类指标（如 ATR 百分位）升高时，降低 technical 权重（因为技术信号在高波动环境中噪声更大）；当波动率低位时，恢复 65/35。

但这条建议需要更多数据和更严谨的回测框架支撑，不适合立刻实施。

### 9.4 不做什么

以下优化看起来合理但回测数据不支持：

- **不要盲目增加 momentum_score 权重**。6 月 30 日的数据已经证明，前期涨得多的股票在回调中跌得也多。增加动量权重会在牛转熊的拐点放大亏损。
- **不要简单提高 technical_score 阈值来减少候选股**。4 月 30 日的好时机+高潜力只有 4 只但平均回报 39%——少量高确信候选股的效果极好。问题不在于候选股太少，而在于市场转向时没有防御机制。
- **不要引入更复杂的机器学习模型**。在只有几个信号日的数据量下，复杂的非线性模型不如当前透明的线性加权公式——至少你知道每项因子在做什么，出问题可以追溯。

### 9.5 迭代路线图

```
Phase 1（本周）：市场状态过滤器
  → 防御/正常两档，影响仓位上限和 momentum 权重
  → 改动量小，不碰评分核心

Phase 2（两周内）：行业中性化
  → quality_score 和 risk_control_score 行业内排名
  → 需要改 registry.py 的 run_combo 函数

Phase 3（一个月）：固定阈值改滚动分位数
  → 需要积累更多信号日数据后一次性切换
  → 同时做 A/B 对比验证

Phase 4（长期）：分状态因子权重校准
  → 需要 12+ 信号日数据 + 市场状态标注
  → 建议用简单的线性回归而非复杂模型
```
